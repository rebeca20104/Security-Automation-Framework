# Wazuh SIEM Deployment Guide on AWS EC2

A comprehensive, step-by-step guide to provisioning an AWS EC2 instance and deploying the Wazuh SIEM platform (Indexer, Server, Dashboard, and Filebeat) on Ubuntu.

---

## Prerequisites & Architecture

* **Cloud Provider:** AWS (Amazon Web Services)
* **OS:** Ubuntu (Latest LTS recommended)
* **Minimum Instance Specs:** `t2.xlarge` (4 vCPU, 16 GiB RAM, 50 GiB Storage required for Wazuh)

---

## Step 1: Launch an AWS EC2 Instance

1. Log in to the [AWS Management Console](https://aws.amazon.com/console/) using your **root user email and password**.
2. Search for and select **EC2**, then click **Launch Instance**.
3. Configure the instance settings:
* **Name:** Give your instance a recognizable name (e.g., `wazuh-siem-server`).
* **Application and OS Images:** Select **Ubuntu**.
* **Instance Type:** Choose **`t2.xlarge`** (provides 4 vCPU and 16 GiB RAM).
* **Key Pair:** Select an existing key pair or **Create a new key pair** (download and keep it safe).
* **Network Settings:** Enable checkboxes to **Allow SSH traffic** and **Allow HTTPS traffic** from the internet.
* **Configure Storage:** Change the volume size to **`50` GiB** (required for Wazuh logs and indexing).


4. Click **Launch Instance**.

---

## Step 2: Connect to the EC2 Instance via SSH

Open your terminal (e.g., Windows Terminal, PowerShell, or Git Bash) from the folder where your `.pem` key pair is stored, and run the SSH command:

```bash
ssh -i "C:\Users\user\Downloads\PROKEY.pem" ubuntu@<YOUR_EC2_PUBLIC_IP>

```

*(Note: Replace `PROKEY.pem` with your actual key pair filename and `<YOUR_EC2_PUBLIC_IP>` with your instance's public IPv4 address).*

---

## Step 3: Deploy Wazuh on Ubuntu

Once logged into your EC2 terminal, update the system packages and deploy Wazuh using the official automated installation script.

### 1. Update System Packages

```bash
sudo apt update && sudo apt upgrade -y

```

### 2. Download the Wazuh Installation Script

```bash
curl -sO https://packages.wazuh.com/4.11/wazuh-install.sh

```

### 3. Execute the Automated Installation

```bash
sudo bash ./wazuh-install.sh -a

```

---

## Step 4: Verify Installation & Access Web UI

1. **Credentials & URL:** Once the script finishes, look at the terminal output for your **generated admin password** and the Web UI URL (`https://<EC2_PUBLIC_IP>`). *Make sure to save these credentials securely.*
2. **Access the Dashboard:** Open your browser and navigate to `https://<EC2_PUBLIC_IP>`. Log in using the default username (`admin`) and the password generated by the script.

---

## Step 5: Verify Core Services & Troubleshooting

If you need to verify that all Wazuh components are running correctly, run the following status check inside your EC2 SSH session:

```bash
sudo systemctl status wazuh-indexer wazuh-manager wazuh-dashboard filebeat --no-pager

```

### Security Group Inbound Rules

Ensure your EC2 instance's Security Group allows inbound traffic for:

* **TCP 443** (Wazuh Dashboard Web UI)
* **TCP 1514 / 1515** (Wazuh Agent communication)

### Quick Troubleshooting Commands

If services fail to start automatically, use these commands to restart the dashboard:

```bash
sudo systemctl start wazuh-dashboard
sudo systemctl daemon-reload
sudo systemctl restart wazuh-dashboard

```

---

## Step 6: Deploying Agents

1. Navigate to the **Wazuh Dashboard** web interface.
2. Go to the agent deployment section to generate registration commands tailored to your environment.
3. Run the provided commands in your endpoint terminal (e.g., Kali Linux) to install and connect your new Wazuh agent back to the server.
